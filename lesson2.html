Lesson 2: Networking Fundamentals

Welcome to Lesson 2! In this lesson, you will learn how computers communicate and how networks support cybersecurity.

1. What Is a Computer Network?

A computer network is a group of computers and other devices connected so that they can communicate and share information or resources.

Examples: A school computer laboratory, an office network, and devices connected to a home Wi-Fi router.

2. Types of Computer Networks

  • LAN (Local Area Network): Connects devices within a limited area, such as an office or school.
  • WAN (Wide Area Network): Connects networks across large geographical areas.
  • WLAN (Wireless Local Area Network): A LAN that uses wireless communication, such as Wi-Fi.
  • PAN (Personal Area Network): Connects personal devices over a short distance, such as Bluetooth devices.

3. What Is an IP Address?

An IP address identifies a device or network interface for communication over an Internet Protocol network.

Example IPv4 address: 192.168.1.10

IPv4 addresses use four numbers separated by dots. Each number ranges from 0 to 255.

4. What Is a MAC Address?

A MAC address is a link-layer address used to identify a network interface on a local network. Its format often looks like this: 00:1A:2B:3C:4D:5E.

5. What Are Network Ports?

Ports help a computer direct network traffic to the appropriate service or application.

  • Port 80: Commonly used for HTTP.
  • Port 443: Commonly used for HTTPS.
  • Port 53: Commonly used for DNS.
  • Port 25: Traditionally used for SMTP email transfer.

6. Common Network Protocols

  • TCP: Provides reliable, ordered delivery of data.
  • IP: Helps route data packets between networks.
  • DNS: Translates domain names into information such as IP addresses.
  • HTTP: Transfers web content.
  • HTTPS: Protects web communication using encryption.
  • DHCP: Automatically assigns IP configuration to devices.

7. What Is a Router?

A router forwards data between different networks. A home router often connects your local devices to the internet.

8. What Is a Firewall?

A firewall monitors and filters network traffic according to security rules. It helps prevent unauthorized network connections.

9. Basic Network Security Practices

  • Use strong Wi-Fi passwords.
  • Change default router administrator passwords.
  • Keep router firmware and devices updated.
  • Use WPA2 or WPA3 Wi-Fi security when available.
  • Avoid suspicious links and unknown network devices.
  • Only scan or test networks when you have permission.

10. How Data Travels Across a Network

When you open a website, your device sends requests and receives responses through a series of network connections.

  1. Your browser identifies the website you want to visit.
  2. DNS helps find the IP address associated with the domain name.
  3. Your device sends network data through your router or other network equipment.
  4. The request travels through the network to the destination server.
  5. The server responds, and your browser displays the content.

Data is commonly divided into smaller units for transmission. Network protocols help devices address, transmit and interpret data.

11. DNS and DHCP

  • DNS (Domain Name System): Helps translate domain names, such as example.com, into IP addresses.
  • DHCP (Dynamic Host Configuration Protocol): Automatically provides devices with network settings, such as an IP address, on networks configured to use it.

Remember: DNS helps locate services by name, while DHCP helps devices obtain network configuration.

12. Private and Public IP Addresses

A private IP address is used within a local network. A public IP address is used to identify a connection or interface on the public internet.

Common private IPv4 address ranges include:

  • 10.0.0.0 to 10.255.255.255
  • 172.16.0.0 to 172.31.255.255
  • 192.168.0.0 to 192.168.255.255

For example, 192.168.1.10 is a private IPv4 address. A router often allows multiple private-address devices to share an internet connection.

13. Wi-Fi Security

  • Use WPA2-AES or WPA3 security where supported.
  • Set a strong, unique Wi-Fi password.
  • Change the router's default administrator password.
  • Install firmware updates from the router manufacturer.
  • Review connected devices and remove unfamiliar devices using your router's administration settings.
  • Avoid sensitive activities on untrusted networks unless you have suitable protection.

14. Basic Network Troubleshooting

  1. Check that Wi-Fi is enabled or the network cable is connected.
  2. Check whether other devices can access the network.
  3. Restart your device if appropriate.
  4. Check the router's connection and status indicators.
  5. If permitted, use built-in network diagnostics to investigate connection problems.
  6. Contact your network administrator or internet provider if the problem continues.

15. Practical Activity

A computer connects to Wi-Fi but cannot open websites. List three checks you would perform before asking for technical support.

Reveal suggested answer

Check whether other devices can browse, verify the computer's network connection, and check whether the issue affects one website or all websites. Further troubleshooting may examine DNS settings and the internet connection.
