Lesson 2: Networking Fundamentals

Welcome to Lesson 2! In this lesson, you will learn how computers communicate and how networks support cybersecurity.

1. What Is a Computer Network?

A computer network is a group of computers and other devices connected so that they can communicate and share information or resources.

Examples: A school computer laboratory, an office network, and devices connected to a home Wi-Fi router.

2. Types of Computer Networks

  • LAN (Local Area Network): Connects devices within a limited area, such as an office or school.
  • WAN (Wide Area Network): Connects networks across large geographical areas.
  • WLAN (Wireless Local Area Network): A LAN that uses wireless communication, such as Wi-Fi.
  • PAN (Personal Area Network): Connects personal devices over a short distance, such as Bluetooth devices.

3. What Is an IP Address?

An IP address identifies a device or network interface for communication over an Internet Protocol network.

Example IPv4 address: 192.168.1.10

IPv4 addresses use four numbers separated by dots. Each number ranges from 0 to 255.

4. What Is a MAC Address?

A MAC address is a link-layer address used to identify a network interface on a local network. Its format often looks like this: 00:1A:2B:3C:4D:5E.

5. What Are Network Ports?

Ports help a computer direct network traffic to the appropriate service or application.

  • Port 80: Commonly used for HTTP.
  • Port 443: Commonly used for HTTPS.
  • Port 53: Commonly used for DNS.
  • Port 25: Traditionally used for SMTP email transfer.

6. Common Network Protocols

  • TCP: Provides reliable, ordered delivery of data.
  • IP: Helps route data packets between networks.
  • DNS: Translates domain names into information such as IP addresses.
  • HTTP: Transfers web content.
  • HTTPS: Protects web communication using encryption.
  • DHCP: Automatically assigns IP configuration to devices.

7. What Is a Router?

A router forwards data between different networks. A home router often connects your local devices to the internet.

8. What Is a Firewall?

A firewall monitors and filters network traffic according to security rules. It helps prevent unauthorized network connections.

9. Basic Network Security Practices

  • Use strong Wi-Fi passwords.
  • Change default router administrator passwords.
  • Keep router firmware and devices updated.
  • Use WPA2 or WPA3 Wi-Fi security when available.
  • Avoid suspicious links and unknown network devices.
  • Only scan or test networks when you have permission.
