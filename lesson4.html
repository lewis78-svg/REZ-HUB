Lesson 4: Ethical Penetration Testing

Welcome to Lesson 4! This lesson introduces authorized security testing, its stages, common tools, responsible reporting, and safe ways to practise cybersecurity skills.

1. What Is Ethical Penetration Testing?

Ethical penetration testing is an authorized assessment of a computer system, network, or web application to identify security weaknesses before malicious attackers exploit them.

Ethical testers work within an agreed scope, protect confidential information, and report findings responsibly.

2. Why Is Penetration Testing Important?

  • Identifies security weaknesses.
  • Helps organizations improve their defences.
  • Tests whether security controls work as intended.
  • Reduces the risk of data loss and unauthorized access.
  • Provides recommendations for fixing vulnerabilities.

3. Types of Security Testing

  • Black-box testing: The tester starts with little or no internal knowledge of the target.
  • White-box testing: The tester has detailed information, such as source code or system design.
  • Gray-box testing: The tester has partial internal knowledge or access.

4. The Main Stages of a Penetration Test

Stage 1: Planning and Authorization

Obtain written permission, define the systems that may be tested, agree on the testing schedule, and establish safety limits.

Stage 2: Information Gathering

Collect permitted information about the target, such as its documented technologies and publicly available details.

Stage 3: Vulnerability Assessment

Identify potential weaknesses using approved methods and tools. Validate results carefully to avoid false positives.

Stage 4: Controlled Testing

Where specifically authorized, safely verify whether a weakness can be exploited. Avoid unnecessary disruption, data access, persistence, or changes to systems.

Stage 5: Reporting

Document the findings, their potential impact, evidence, affected systems, and clear recommendations for remediation.

Stage 6: Remediation and Retesting

The system owner fixes the identified issues. The tester can then verify, with permission, whether the fixes are effective.

5. Common Ethical Hacking Tools

  • Wireshark: Examines network traffic in environments where monitoring is authorized.
  • Nmap: Discovers hosts and services on networks you are permitted to assess.
  • OWASP ZAP: Helps test web application security.
  • Burp Suite: Provides tools for authorized web application testing.
  • Linux: Offers a range of command-line and security utilities.

6. Safe Practice Environments

Beginners should practise in deliberately vulnerable training environments rather than testing real systems without permission.

  • OWASP Juice Shop — a deliberately insecure web application for training.
  • PortSwigger Web Security Academy — free web security lessons and practice labs.
  • TryHackMe — guided cybersecurity learning rooms.

7. Rules of Ethical Testing

  • Always obtain explicit authorization before testing.
  • Test only the systems and activities covered by the agreed scope.
  • Do not steal, expose, or unnecessarily access private data.
  • Do not disrupt services or change systems without authorization.
  • Keep evidence secure and protect confidential information.
  • Report findings to the authorized contact responsibly.

8. Quick Quiz

Question 1: What makes penetration testing ethical?

Show answer

Explicit authorization, an agreed scope, safe methods, and responsible reporting.

Question 2: Which testing type starts with little or no internal knowledge?

Show answer

Black-box testing.

Question 3: Why is a report important?

Show answer

It documents weaknesses, their impact, and recommendations for fixing them.

Question 4: Where should beginners practise their skills?

Show answer

In authorized training labs or systems they own and are permitted to test.

Question 5: What should happen after vulnerabilities are fixed?

Show answer

Authorized retesting can verify whether the fixes are effective.
